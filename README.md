A UI Developer technical exam completed in **2021** as part of the application process for **Investagrams**.

The task was to recreate a provided **JPG UI mockup** as a responsive web interface, translating the visual design into a functional implementation across different screen sizes.

## Live Demo

[View Live Demo](https://entrance-exam-investa.netlify.app/)

## Overview

The objective of the technical exam was to demonstrate practical UI development skills, including:

- Translating a visual mockup into a working interface
- Building a responsive layout
- Matching the provided design and visual hierarchy
- Implementing reusable UI components
- Supporting different screen sizes and viewport dimensions
- Maintaining clean and organized frontend code

## Design Reference

The implementation was based on a JPG mockup provided as part of the technical assessment.

> **Note:** The original mockup was provided by Investagrams for evaluation purposes.

## Key Focus

### Responsive Design

The interface was developed to adapt to different screen sizes rather than reproducing the mockup as a fixed desktop layout.

The implementation considers:

- Desktop layouts
- Tablet screen sizes
- Mobile screen sizes
- Flexible spacing and sizing
- Responsive typography
- Content reflow
- Mobile-friendly interactions

### UI Implementation

The design was recreated from the supplied visual reference, with attention to:

- Layout structure
- Typography
- Colors
- Spacing
- Alignment
- Components
- Visual hierarchy
- Responsive behavior
